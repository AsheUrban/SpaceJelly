## Description
_SpaceJelly_ is a 3D interactive space environment created with **Three.js** and JavaScript.  
Originally based on Emilian Kasemi’s tutorial, the project evolved into a collaborative exploration of particle systems, 3D model integration, and camera control techniques.  
Team members experimented with scene composition, lighting, interactivity, and custom geometry to create unique visual and interactive experiences.

The final branch, **wipAllControls**, demonstrates expanded camera controls, new imported models, and adjusted particle behavior for improved visual depth and user engagement.

## Setup/Installation Requirements
* Clone or download this repository:
  ```bash
  git clone https://github.com/AsheUrban/SpaceJelly.git
  ```
* Navigate into the project directory:
  ```bash
  cd SpaceJelly
  ```
* Install dependencies:
  ```bash
  npm install
  ```
* Start the development server:
  ```bash
  npm run dev
  ```
  The project will open automatically in your default browser at:
  ```
  http://localhost:8080/
  ```
* Use the mouse and scroll wheel to navigate through the scene and explore the environment.
